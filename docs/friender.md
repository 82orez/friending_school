## 연습방 게시판 (`20260918070523_add_room_board.sql`)

연습방 상세 모달 「게시판」 탭 — **글(공지/일반) + 댓글**. 샤우팅 게시판(`docs/prep.md`)의 이식본이라 구조·규약은 대부분 같고, **쓰기 자격 하나가 결정적으로 다르다**.

**권한**: **읽기는 누구나**(비로그인 포함, 그 시리즈의 방이 살아 있는 동안). **쓰기는 개설 프렌더 ∥ 로그인한 사용자 전부** — 샤우팅이 '유효 신청자'로 좁힌 것과 달리 **로그인만 하면 예약하지 않아도 쓴다**. 무료·무심사 연습방이라 참여 장벽이 없고, **예약하기 전에 물어볼 창구**가 필요해서다(제품 결정). 대신 **공지는 호스트만**이고, 로그인만으로 열려 있으므로 **rate limit이 사실상 유일한 방어선**이다(글 20/10분·댓글 30/10분). 수정은 **작성자 본인만**, 삭제는 **본인 ∥ 개설 프렌더**(모더레이션과 대필은 다르다).

**테이블 2종**: `friender_room_board_posts` · `friender_room_board_comments`. 컬럼·check·인덱스·트리거는 prep 쌍둥이와 동일하고 ⚠️ **`series_key`에 FK가 없다**(시리즈에 부모 테이블이 없다 — 상세·정리 규칙은 `docs/db.md`).

**액션 `src/app/friending/board-actions.ts`**(`joinRoom`·`enterRoom`과 같은 폴더): `loadRoomBoard(seriesKey, cursor?)` · `createRoomBoardPost` · `updateRoomBoardPost` · `deleteRoomBoardPost` · `createRoomBoardComment` · `deleteRoomBoardComment`. **공지 전량 + 일반 글만 커서 페이징**(⚠️ 섞어 뽑고 JS로 공지를 올리면 2페이지에서 공지가 뒤늦게 올라온다), 댓글은 embed 후 **JS에서 오름차순**(임베드 정렬은 PostgREST로 안 된다), 자격은 서버가 `viewer{canWrite, canPostNotice, reason}`로 내려 준다(**클라는 자체 판정하지 않는다**). 내부 헬퍼 **`seriesHostId`**(`.or(series_id.eq.KEY, and(id.eq.KEY, series_id.is.null))` — 방이 하나도 없으면 null = 시리즈 없음)·`writerRole`(host ∥ member)·`authorSnapshot`(닉네임>성+이름>이메일 앞부분, `joinRoom`과 같은 우선순위)·`normalizeBody`. ⚠️ **`seriesKey`는 uuid 검증 필수** — `.or()` 필터 문자열에 들어간다(`room-actions.ts`의 `isUuid`와 같은 이유). ⚠️ **`revalidatePath`를 부르지 않는다** — 게시판은 어떤 SSR props에도 실리지 않고 패널이 쓰기 성공 후 `loadRoomBoard`를 다시 부른다(`router.refresh()`도 금지 — 홈 전체를 다시 그릴 이유가 없다).

**UI `src/components/friending/RoomSeriesBoard.tsx`**: 공지(상단 고정, `border-brand/20 bg-brand/5` + 빨강 「공지」 배지) → 일반 글 → 「더보기」. 글마다 작성자·프렌더 `F` 배지·`kstDateTimeText`(⚠️ `toLocaleString` 금지 — 하이드레이션 불일치)·수정됨 표시·본문(`whitespace-pre-wrap`)·댓글 목록/입력. 클라 `maxLength`와 서버 `slice`가 `src/data/room-series.ts`의 같은 상수(`ROOM_BOARD_POST_MAX`/`_COMMENT_MAX`, **DB check와 같은 값**)를 본다. 자격 없음 안내는 **비로그인이면 `/login` 링크**, 로그인했는데 `not_eligible`이면 "지금은 글을 쓸 수 없어요"(시리즈가 사라진 경우 정도라 사실상 안 뜬다). ⚠️ 삭제 확인 `AlertDialog`는 **`z-[130]`**(패널 z-[120] 위) — 빠뜨리면 패널 **뒤에** 떠서 눌러도 아무 일도 안 일어나는 것처럼 보인다(`EnterZoomButton`에서 실제로 겪은 버그). 모달의 "서버 액션은 부르지 않는다" 규약의 **예외**다(예약 pending·확인 다이얼로그와 겹치지 않는 자기 완결형 하위 트리 — `PrepCourseBoard`와 같은 판단). `key={series.key}`로 방이 바뀌면 상태를 버린다.
