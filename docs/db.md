## DB 스키마 (`supabase/`)

⚠️ **permissive RLS 정책은 OR로 합쳐진다** — 한 테이블에 SELECT 정책이 둘 이상이면 "RLS가 본인 것만 통과시킨다"는 전제가 깨진다. 소유권이 걸린 화면은 **쿼리에 `.eq("<owner>_id", user.id)`를 명시**할 것(`friender_rooms`·`friender_room_reviews`에서 실제로 남의 데이터가 노출된 회귀가 있었다). 특히 나중에 공개용 `_select_public` 정책을 추가할 때 기존 화면들이 함께 열린다는 점을 기억할 것.
