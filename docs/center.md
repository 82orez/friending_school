**센터 매니저** (`/center`, **UI 영문**(센터 매니저=외국인 다수, 강사 페이지와 동일 정책), 탭 구조): 센터 담당자에게 **소속 센터 강사 조회 + 개별 회차 강사 대체** 권한 부여. **식별=`centers.manager_id`(FK→auth.users, `20260713003440`)** — role enum 미변경, 한 명이 여러 센터 담당 가능. admin이 `/admin/centers` 상세 모달에서 **매니저 계정 지정**(`CenterDetailModal` `<select>`, 후보=listUsers+profiles; `updateCenter(id,name,managerName,managerId)`가 `manager_id` set·계정 존재검증). **가드 `src/lib/center-manager.ts`**: `requireCenterManager()`(세션→`loadManagedCenters`(service_role, `manager_id=uid`)→담당 센터 없으면 null, 액션·page 첫 줄 가드)·`isCenterManager`. `layout.tsx`가 `centers.manager_id=user.id` 존재로 `isCenterManager` 파생→Navbar **"센터 관리"** 링크. 조회는 전부 **가드 후 service_role**(매니저는 admin 아님, profiles RLS는 본인만) — 새 RLS 불필요. **`/center/layout.tsx`(route group 아님) 가드+웰컴+`<CenterTabs>`(라벨 영문: Teachers `/center`·Weekly Schedule `/center/schedule`·Settlement `/center/settlements`)**. **① 강사 관리**(`page.tsx`→`loadCenterTeachers(admin,centerIds)` `src/lib/teacher-directory.ts`=admin `teacher-requests`의 `CurrentTeacher[]` 조립 센터 스코프 이식)→`<CenterTeachers>`가 admin `CurrentTeacherTable`(목록)+`TeacherClassesModal`(진행 중 강좌)+`TeacherInfoModal` **`readOnly`**(센터 변경·단가(급여) 숨김, 프로필·가용·PDF만) 재사용. **② 주간 일정**(`schedule/page.tsx`→`loadCenterSessions`+`loadCenterTeacherCards`)→`<CenterWeekSchedule>`(1분 틱)→admin **`<ClassWeekGrid readOnly onReassign>`** 재사용. **강사 대체는 주간 SlotModal 인라인**: `readOnly && onReassign && 미시작`(`now<시작시각`) 회차 행에 **"강사 대체"** 버튼→SlotModal 닫고 `<ReassignModal>`(`src/components/center/`, 같은 센터·그 시간 가용 강사만 `teacherHasAllSlots` 후보)→**`centerReassignClass(classId,newTeacherId)`**(아래). **강사 피드백 열람도 SlotModal 인라인**(readOnly 분기): `s.feedback` 있는 회차 행에 **"View feedback"**(Eye) 버튼→읽기 전용 `SlotFeedbackModal`(같은 파일, 이중언어, 오버레이 z-[130]/패널 z-[140]=SlotModal 위, `data-slot-feedback`로 SlotModal Esc 가드→피드백만 닫힘; 날짜+본문). admin 주간 SlotModal은 non-readOnly(행 전체=상세 링크 버튼, 버튼 중첩 불가)라 미노출·무변경(admin은 `ClassesManager`에서 피드백 열람).(`src/app/center/actions.ts`, `requireCenterManager`→**공유 코어 `reassignClassCore`**(`src/lib/reassign.ts`)에 `actor.role='center_manager'`·`constrainCenterIds` 전달=현재·새 강사 모두 담당 센터 소속이어야 통과). **`ClassWeekGrid`의 `AdminSession`에 `classId`·`teacherId`·`sessionNo`(대체 대상)·`period`(수업 일정 `scheduleDateRange`)·`totalSessions`(수업 횟수)·`course`(영어 과정명 해석용 슬러그)·**`feedback?`/`feedbackAt?`(옵셔널 — SlotModal 피드백 열람용, `loadCenterSessions`만 채움·admin 빌더 무변경)** 추가** — admin `/admin/classes`·center 로더 두 파이프라인이 공급, admin은 `onReassign` 미전달=버튼 없음·행 클릭 드릴인 유지(무변경). **③ 정산**(`settlements/page.tsx`→담당 센터 소속 강사 id 해석(`profiles.role='teacher'`·`in center_id`)→**공유 로더 `loadSettlementRows(admin,teacherIds)`**(`src/lib/settlements.ts`, admin 정산 page의 row 조립 이관=teacherIds 필터, 빈 배열=빈 결과)→admin **`<SettlementsManager>`** 재사용, props `initialGrouping="강사별"`·`groupings={["강사별"]}`(분류 토글 숨김)·`enableTeacherDetail`(강사 행 클릭→`TeacherSettlementModal` 상세)·**`showKrwEquivalent={false}`**(외화 정산 센터엔 `≈₩` 환산 생략, 합계는 통화별 집계; 원화 센터는 네이티브 ₩ 그대로). 센터 매니저 강사 대체 시 `reassignClassCore`가 **관리자 알림 메일**(`sendClassReassignToAdmin`)도 발송(admin 본인 대체는 제외). **④ 이메일 알림 수신**: 소속 강사(=`profiles.center_id`가 담당 센터)의 **수강신청 6시점**(접수·강사 승인·강사 거절·수업 확정(결제)·취소(학생/admin)·환불) + **admin의 수업 변경 4시점**(1회성 강사 대체·연기·취소·남은 일정 일괄 변경·남은 수업 전체 강사 대체)에 영문 알림 수신 — 오케스트레이션은 **`src/lib/center-notify.ts`**(헬퍼 항목: `notifyCenterManagerOfEnrollment`/`notifyCenterManagerOfClass`), 메일은 `sendEnrollmentEventToCenterManager`·`sendClassEventToCenterManager` 두 단일 함수. **본인이 실행한 변경은 미수신**(`actorId` 제외). **영어화 방식(로케일 컨텍스트)**: 앱은 i18n 라이브러리 없이 오디언스별 하드코딩(학생 한글·강사/센터 영문·admin 한글)인데, 센터가 **admin과 공유하는 컴포넌트 5종**(`CurrentTeacherTable`·`TeacherInfoModal`·`TeacherClassesModal`·`ClassWeekGrid`(+SlotModal)·`SettlementsManager`)이 admin(한글)에도 쓰여 이중언어 필요 → **`src/components/LangProvider.tsx`**(`LangProvider`/`useLang()`, **기본 `"ko"`**) 컨텍스트로 `/center` 레이아웃만 `<LangProvider lang="en">`로 감싸고, 공유 5종은 `const en = useLang()==="en"`로 문자열 분기(영어 과정명=**`getCourse(course)?.englishTitle ?? courseEnglishTitle ?? courseTitle`**(classroom.ts와 동일 체인 — 커스텀 테스트 과정(`course="custom"`, 레지스트리에 없음)은 DB `course_english_title`로 폴백; 이를 위해 `SettlementRow`·`AdminSession`·`TeacherClassItem` 3개 DTO에 `courseEnglishTitle` 필드 + `loadSettlementRows`/`loadCenterSessions`/`loadCenterTeachers`가 `course_english_title` select·매핑)·`nationalityLabelEn`/`genderLabelEn`·`summarizeSlots(_,false)`·`formatDate`; 정산 Period/Grouping enum **값은 내부 한국어 key 유지**, 표시 라벨만 로케일 맵). **admin은 provider 없어 기본 ko=무변경**. 센터 전용 컴포넌트(layout·`CenterTabs`·`CenterTeachers`·`CenterWeekSchedule`·`ReassignModal`)는 강사 페이지처럼 영어 하드코딩(`ReassignModal`은 서버 실패 시 raw 한국어 대신 일반 영어 메시지). **`SettlementDetailModal`은 admin 전용**(센터는 강사별만)이라 한글 유지. **⚠️ 공유 5종 문자열 수정 시 en/ko 양쪽 유지.**
