# 루트 레이아웃 · 스타일링 토큰 · shadcn/ui

> `CLAUDE.md`에서 분리된 상세 문서. 본문의 "위 …항목" 상호참조는 다른 `docs/*.md`일 수 있음(색인=CLAUDE.md).

**루트 레이아웃** `src/app/layout.tsx`(async server): `getUser()` + **`getUserRole` 1회**로 `isAdmin`/`isTeacher`/`isFriender` 파생 + `centers.manager_id=uid` count로 `isCenterManager` 파생 → `<Navbar user isAdmin isTeacher isCenterManager>`. `<AuthHashHandler/>`(`src/components/auth/`)를 마운트해 implicit hash(`#access_token=...`) 토큰을 client에서 `setSession` 후 `/?verified=success` 또는 `/reset-password`로 replace. `lang="ko"`, Pretendard(`next/font/local`, `--font-pretendard`) + Geist(`--font-sans`). **단, `globals.css`의 `@theme inline`이 `--font-sans`·`--font-heading` 모두 `→ "Twemoji Country Flags", var(--font-pretendard)` 매핑이라 `font-sans`는 Pretendard**(맨 앞 **Twemoji Country Flags** 웹폰트는 `@font-face` `unicode-range`로 국기 코드포인트에만 적용 — Windows/Linux 등 국기 글리프 없는 OS에서 `🇰🇷`가 "KR" 텍스트로 깨지는 것 방지, 폰트 `public/fonts/TwemojiCountryFlags.woff2` 자체호스팅, 일반 텍스트엔 영향 없음).

**스타일링** Tailwind v4: `globals.css`의 `@import` + `@theme inline`(별도 config 없음). `@custom-variant dark`. 토큰 세 그룹: (1) shadcn 색상/`--radius-*`(OKLch), (2) **마케팅 시맨틱 색**: `--color-brand`(#ff4757, 인증/강조 빨강), `--color-brand-blue`(#2563eb, **회원가입 동선 전용**), `--color-ink`(#1a1a1a), `--color-ink-soft`(#333), `--color-surface`(#f8f8f8), `--color-muted-fg`(#666), `--color-muted-fg-faint`(#999), `--color-rule`(#eee), `--color-rule-faint`(#ddd), (3) **project0607 플랫폼 팔레트(블루→핑크)**: `--color-accent-blue`(#6b8ff0)·`--color-accent-blue-soft`(#eef1fd)·`--color-accent-blue-ink`(#4a6bd4, 링크/탭 강조), `--color-cta`(#1a4fa0, **네이비 — 범용 CTA**: 수강신청·강사/센터/유튜브 admin 액션 버튼 등), `--color-progress`(#b22222). + `@layer utilities`의 **`.bg-brand-gradient`/`.text-brand-gradient`**(블루→핑크 135deg, 히어로 "세계로"·섹션 라벨·탭 active·로고). **새 코드는 하드코딩 hex 금지, 토큰 클래스 사용**(예외 단발성: #E05A6A 신청박스, #ffc107/#F5A623 별점, #aaa 등). 다크모드 미구현. `@layer base`: 활성 버튼 `cursor:pointer` 전역 + smooth 스크롤은 `html[data-scroll-behavior="smooth"]`에만 적용(layout.tsx `<html data-scroll-behavior="smooth">`). **⚠️ CSS로 `html{scroll-behavior:smooth}` 직접 선언 금지** — 라우트 네비게이션 시 Next가 끄지 못해 페이지 이동 후 최상단 점프 실패(교재 등 상단 가림). data 속성으로 선언해야 Next가 전환 중 일시 비활성화.

**shadcn/ui** `components.json`(`base-nova`/`neutral`/lucide/RSC). UI: `src/components/ui/{button,card,input,label,textarea,alert-dialog,calendar,popover,select,sonner,tooltip}.tsx`. `select.tsx`는 미사용(tracked). **`tooltip.tsx`**(base-ui `Tooltip`)는 현재 **`RoomsManager` 아이콘 버튼 3종(공개토글·수정·삭제) 전용** — `TooltipTrigger`는 **기본 렌더 요소가 `<button>`**이라 `type`/`onClick`/`disabled`/`aria-*`를 그대로 전달하면 되고 별도 래핑이 필요 없다. `TooltipProvider`는 루트 layout이 아니라 **`RoomsManager` 내부에서 로컬로** 감쌌다(다른 화면으로 퍼지면 layout으로 올릴 것). **`sonner.tsx`=토스트**(라이브러리 `sonner`, next-themes 없이 `theme="light"` 고정 래퍼 — `position="top-center"` `richColors`; `layout.tsx`에 전역 `<Toaster/>` 마운트, 강사 폼 등에서 `toast.success/error`). `calendar.tsx`는 **수강신청 위저드 시작일 선택**(`EnrollWizard` step 2) + **내 강의실 과정 달력**(`ClassroomList`) + **admin 수업 상세 달력**(`ClassesManager`) 3곳에서 사용(`date-fns`(^4) + `react-day-picker`(^10), 로케일 `ko`/`enUS`), `popover.tsx`는 미사용. `cn()`은 `src/lib/utils.ts`(clsx+tailwind-merge), 항상 사용. 아이콘 `lucide-react`, 프리미티브 `@base-ui/react`, 애니메이션 `tw-animate-css`.

- **Button variant**: shadcn 기본 + 추가 4종 — `brand`(빨강 primary), `brand-blue`(파랑, **회원가입 동선 전용**: SignupForm 제출·AlertDialogAction "보내기"), `brand-inverse`(흰, 빨강 배경 위), `kakao`(#FEE500/#191919, `KakaoButton` 전용, 고정 hex). `buttonVariants`로 `<a>`에도 적용. (네이비 CTA는 variant 아닌 `bg-cta` 클래스 — 수강신청·admin 액션 등.)
- ⚠️ **base-nova**: `AlertDialogAction`은 `Close`로 안 감싸져 **클릭해도 모달 자동 안 닫힘** → onClick에서 `setOpen(false)` 또는 controlled 사용. `AlertDialogCancel`은 정상.

**`SectionCard`** (`src/components/SectionCard.tsx`): 카드 div wrapper. variant 3종 — `accent-left`(`border-l-[6px] border-brand bg-surface`), `outline`(`border border-rule bg-surface`, 현재 전자책 Unit 목록에서 사용), `plain`(`bg-surface`). `rounded/p`는 호출 측 className. shadcn `Card`(슬롯)는 별개.

**이미지(`next/image`)**: 자산은 `public/images/`, 호출은 **`relative` 래퍼 + `fill` + `sizes` + `object-cover`**가 앱 공통 규칙(장식 이미지는 `alt=""`, above-the-fold 히어로만 `priority`). 원형 아바타는 래퍼에 `size-* overflow-hidden rounded-full`, 배경이 흰 사진이면 흰 카드 위에서 원 경계가 사라지므로 `ring-1 ring-rule`을 더한다. **SVG는 `next/image`로 서빙하지 않는다** — `images.dangerouslyAllowSVG`가 필요해서, 일러스트는 **JSX 인라인 SVG 컴포넌트**로 만든다(`src/components/prep/PrepHeroArt.tsx`·`/friending` 히어로 선례). ⚠️ **같은 파일명으로 이미지를 교체하면 화면이 안 바뀐다** — Next 16 dev는 최적화 결과를 **`.next/dev/cache/images/`**(Next 15까지의 `.next/cache/images`가 **아님**)에 **TTL 4시간(파일명에 `14400`)**으로 저장하고, **dev 서버를 재시작해도 디스크 캐시가 살아남아 `X-Nextjs-Cache: HIT`로 옛 이미지를 계속 돌려준다**(실제로 사진 교체 후 한참 헤맴). 해결은 **`rm -rf .next/dev/cache/images`** + 브라우저 하드 리프레시. 확인은 `curl -sD - -o /dev/null "http://localhost:3000/_next/image?url=%2Fimages%2F<파일>&w=256&q=75" | grep -i x-nextjs-cache`(MISS면 새로 최적화된 것). macOS에서 자산 리사이즈·크롭은 `sips`(`-Z 512` 축소 · `-c H W --cropOffset Y X` 오프셋 크롭 · `-p H W --padColor FFFFFF` 정사각 패딩)로 충분하다.
