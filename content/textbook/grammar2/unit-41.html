문장을 연결해요!

접속사 — and / but / or / so / because
POINT

접속사는 문장과 문장을 연결해주는 다리예요. 단어와 단어, 문장과 문장을 이어서 하나로 만들어 줘요!

접속사뜻예문
and그리고I like tea and coffee.
but그러나, 하지만It's small but nice.
or또는, 아니면Tea or coffee?
so그래서I was tired, so I slept.
because왜냐하면 (~때문에)I slept because I was tired.
문장 + 접속사 + 문장 예) I was tired, so I slept.  ·  I slept because I was tired.
💡 짝으로 기억

so(결과)와 because(이유)는 짝이에요. 순서가 반대예요! 결과는 so 앞, 이유는 because 뒤. and(추가) / but(반대) / or(선택)도 함께 익혀 두세요.

저는 피곤하고 배고파요.
I'm tired and hungry.
마음에 들지만 비싸요.
I like it, but it's expensive.
걷거나 버스를 탈 수 있어요.
We can walk or take a bus.
비가 와서 집에 있었어요.
It rained, so I stayed home.
📌 포인트: and(추가) / but(반대) / or(선택)  |  so(그래서, 결과) ↔ because(왜냐하면, 이유)
