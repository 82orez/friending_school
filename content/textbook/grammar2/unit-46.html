UNIT 46

만약 ~하면, ~할 거예요!

가정법 1 — If + 현재형, will + 동사원형
POINT

가정법 1은 실제로 일어날 수 있는 일을 말할 때 써요. "만약 ~하면 (지금 조건), ~할 거예요 (앞으로 결과)"의 구조예요.

자리형태예문
If절 (조건)현재형! (will ❌)If it rains tomorrow,
주절 (결과)will + 동사원형I will stay home.
If + 현재형,  주어 + will + 동사원형 If I have time, I will call you.  ·  If you study hard, you will pass.
💡 꼭 기억

if절 안에서는 미래 이야기라도 will을 쓰지 않아요! ❌ If it will rain tomorrow → ✔ If it rains tomorrow  |  ❌ If you will study hard → ✔ If you study hard

만약 내일 비가 오면, 집에 있을 거예요.
If it rains tomorrow, I will stay home.
열심히 공부하면 시험에 합격할 거예요.
If you study hard, you will pass the test.
시간이 있으면 전화할게요.
If I have time, I will call you.
피곤하면 쉬어야 해요.
If you are tired, you should rest.
📌 포인트: If절 = 현재형 (will 금지!)  |  주절 = will + 동사원형  |  실제로 일어날 수 있는 일이에요!

TALK — English
📍 Scene. Two friends talking about weekend plans
Anna: Do you have plans this weekend?
Ben: If it is sunny, I will go for a walk in the park.
Anna: What if it rains?
Ben: If it rains, I will watch a movie at home.
Anna: That sounds relaxing. Who will you spend time with?
Ben: If my friends are free, I will invite them for dinner.
Anna: Sounds great!
Ben: If you have time, come over too!
💡 Key sentences
If + present (is / rains / are)
main clause = will + base verb
no will inside the if-clause!
