UNIT 48

그때 ~했더라면!

가정법 3 — If + had p.p., would have p.p.
POINT

가정법 3은 이미 지나간 과거를 다르게 상상할 때 써요. 주로 후회 · 아쉬움 · 지나간 일에 대한 상상을 말할 때 사용해요!

구분의미예문
가정법 1앞으로 일어날 일
If + 현재형, will ~		If it rains, I will stay home.
가정법 2현재와 다른 상상
If + 과거형, would ~		If I were rich, I would travel.
가정법 3과거와 다른 상상 (후회)
If + had p.p., would have p.p.		If I had known, I would have helped you.
If + had p.p.,  주어 + would have + p.p. 예) If I had known, I would have helped you.
💡 대비로 기억

If절 = had p.p. (과거보다 더 이전 느낌), 주절 = would have p.p.로 짝지어 기억하세요. should have p.p.(~했어야 했는데) · I wish I had p.p.(~했더라면 좋았을 텐데)도 함께 익혀 두세요.

알았더라면 도와줬을 텐데. (몰랐어요)
If I had known, I would have helped you.
더 공부했더라면 합격했을 텐데.
If I had studied harder, I would have passed.
너에게 전화했어야 했는데.
I should have called you.
영어를 더 일찍 배웠더라면.
I wish I had learned English earlier.
📌 포인트: If절 = had p.p. (과거의 과거, 그때)  |  주절 = would have p.p.  |  후회 = should have p.p.
