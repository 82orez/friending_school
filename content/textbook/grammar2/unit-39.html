UNIT 39

네가 해줬으면 해요!

목적어 + to 동사 — want / need / ask / tell
POINT

영어는 "누가 행동하는가?"를 아주 중요하게 생각해요. 주어 + 동사 + 사람 + to + 동사원형 → "~가 ~하길 원하다"가 돼요!

동사 + 사람 + to예문뜻
want + 사람 + toI want you to stay.네가 머물길 원해요.
need + 사람 + toI need you to help me.당신 도움이 필요해요.
ask + 사람 + toI asked you to wait.기다려 달라고 부탁했어요.
tell + 사람 + toI told you to come early.일찍 오라고 했어요.
주어 + 동사 + 사람 + to + 동사원형 Do you want me to help?  ·  What do you want me to do?  ·  Where do you want me to sit?
💡 대비로 기억

I want to go (내가 가요) ↔ I want you to go (네가 가요). 사이에 사람이 들어가면 행동하는 사람이 바뀌어요! "Do you want me to ~?" = 내가 ~해줄까요? (배려·제안)

네가 머물길 원해요.
I want you to stay.
내가 도와줄까요?
Do you want me to help?
당신이 기다려 줬으면 해요.
I need you to wait.
오라고 부탁했어요.
I asked you to come.
📌 포인트: I want to go (내가 가요) ≠ I want you to go (네가 가요)  |  항상 사람 + to + 동사원형!
